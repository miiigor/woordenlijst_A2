# Тренажёр нидерландского A2 (PWA)

Личный тренажёр лексики Taalcompleet A2 (темы 1–8). Без сервера, аккаунтов и аналитики: всё хранится в IndexedDB на устройстве.

## Запуск
Service Worker и установка на экран «Домой» требуют HTTPS (или localhost). `file://` не подходит.
- Локально: `python3 -m http.server 8080` в этой папке, затем http://localhost:8080
- На iPhone: выложите папку на любой статический хостинг с HTTPS (GitHub Pages, Netlify, Cloudflare Pages).

## Установка на iPhone
1. Откройте адрес в Safari и дождитесь полной загрузки (один раз нужен интернет).
2. «Поделиться» → «На экран „Домой“».
3. Дальше приложение работает без интернета.

## Словарь
`vocabulary.json`: 939 записей, из них 149 со звёздочкой (`excluded: true`, в обучение не попадают).
Поля: `id, dutch, russian_original, russian_reviewed, review_status, review_note, excluded`.
Статусы: `unchanged` (842), `corrected` (92), `needs_context` (5). Оригинал из PDF всегда сохранён в `russian_original`.
Проверка переводов выполнена по моему знанию языка, это не экспертная вычитка: спорные места стоит просмотреть самому.
Чтобы обновить словарь, поднимите `version` в файле и `V` в `sw.js`: новые данные подтянутся, прогресс сохранится.

## Обучение
- Два направления, прогресс и расписание у каждого свои.
- «Знаю» / «Не знаю» после «Показать ответ»; «Показать варианты» даёт до 4 вариантов из словаря.
- Баллы: 1 без подсказки, 0,5 с вариантами, 0 за ошибку.
- Расписание (`srs.js`, `STEPS` и функция `schedule`): верно — интервал 1, 2, 4, 8… дней; верно с подсказкой — интервал растёт лишь ×1,3 (минимум 1 день), уровень не растёт; ошибка — повтор через 10 минут, в сессии карточка вернётся через ~4 карточки.
- За сессию добавляется до 20 новых слов на направление (`NEW` в `app.js`).

## Резервная копия
В самом низу главного экрана: «Резервная копия» → «Экспорт JSON» (сохраните файл в «Файлы»/iCloud) и «Импорт JSON». Импорт проверяет структуру и, если файл повреждён, ничего не меняет; запись идёт одной транзакцией.
Данные Safari могут очищаться, если приложение долго не открывать: делайте копию периодически.

## Проверки
`node tests.js` проверяет баллы, расписание, независимость направлений, варианты ответа, валидацию импорта.
